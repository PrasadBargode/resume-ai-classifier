# 🧠 AI-Powered Resume Classifier & Insights Dashboard

Automatically classify resumes into job roles like Data Science, Web Development, HR, etc.  
Extract skills, keywords, and generate intelligent visual insights.

## Features
- Resume Category Prediction (ML)
- PDF/DOCX Upload and Parsing
- Named Entity Recognition (Skills, Location, Org)
- Word Clouds, Pie Charts, Resume "Fit Score"
- Built using Streamlit, Python, Scikit-learn, SpaCy
